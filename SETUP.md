# Setup: Claude Code + a Project + (optional) Chrome testing (about 45 minutes, once)

1. **Put the project in a folder on your computer** (unzip 2d12-project.zip), and make it a git repository (`git init`, `git add .`, `git commit -m "start"`). A private GitHub repository is a good backup (optional). Git is your undo for every change.
2. **Install Claude Code** (the desktop app, its Code tab, is the easiest; a terminal or VS Code also work). Open the folder. `CLAUDE.md` in the folder is read at the start of every session: it already has the commands and your rules. Add to it every time Claude repeats a mistake.
3. **Foundry, no more zips:** make `foundry/twod12` appear in Foundry's `Data/systems/twod12` (a link or a copy done by one command; ask Claude Code to do it for your system). After a change, reload Foundry (F5) and test.
4. **(Dropped 2026-11-17: no claude.ai Project, PROJECT-INSTRUCTIONS.md deleted; design and mockups happen in Claude Code.)**
5. **Optional, try it once:** install the Claude in Chrome extension, run Claude Code with `claude --chrome` (or `/chrome` in a session), open your Foundry world in Chrome, and ask it to run a version's test checklist. It is a beta; keep your own test as the truth until you trust it.
6. **Each pack:** a new Claude Code session, "Read HANDOFF.md and MASTER-PLAN.md and run pack N". Design sessions and mockups too, in Claude Code.
