# 2d12 System (Draft) for Foundry VTT V14

The Foundry VTT system of the 2d12 homebrew RPG (id `twod12`). The version is in `system.json`.

- **Install:** copy the `twod12` folder into `Data/systems/` (or unzip `twod12.zip` there), restart Foundry and create a world with this system.
- **How it works, and the changelog:** `docs/reference.md`.
- **The Paladin (v0.0.409, pack F2):** Foundry reads the redesigned Paladin's Structure cards (`book/cards/stage0/paladin.json`, each with its `foundry` block) through `book/cards/load.mjs` loadFoundryCards; the ruler keeps the old `paladin.json`. Its mechanics: `module/judge.mjs` (Judge, Profane, Smite's dice), `module/hooks.mjs` (the passives' hooks), `module/split.mjs` modeView (an Art's Modes), the moment `enemyAway` (Rebuke), the condition Half-Blinded, a Zone's Guard row. Test t255.
- **Stage 0 (v0.0.407, pack F1):** the book's Stage 0 rules. The pure rules are `module/roundrules.mjs` (Escalation 1 to 6, Momentum 0 to 4, the Doomed shot, the Minions' squads, the thrown penalty) and `module/npcbudget.mjs` (the Bestiary's turn budget, the CV steps, the role presets); both are shared with the ruler (`book/ruler/sim`). Exploding dice are `module/explode.mjs` (Foundry's die modifier `xs`: "1d6!" is rolled as "1d6xs"). The world migration is `module/migrater.mjs` migrateS0.
- **The Action sheet, Create Button and Generate Action (v0.0.355 to v0.0.357, PACK ACTION-SHEET):** Lucas's picks (`foundry/mockups/action-sheet-A2.html`, `button-builder.html`, `generate-action.html`; the audit `foundry/mockups/action-effects-audit.md`). The Action's Details tab is `module/actionsheet.mjs` (the HTML and the events; built with the Effect sheet's fr- pieces, its own CSS the `v0.0.355` block at the end of `styles/system.css`); a Version's "After the damage" chain as steps and the order of events are the pure `module/aftersteps.mjs` (test t241). Create Button is `module/builder.mjs` (test t242); Generate Action reads a card written as text with `module/gencard.mjs` (pure, test t243) in the window `module/genwindow.mjs`. An Action holds rules like a Feature (`data.mjs`, `passives.mjs`). `module/versions.mjs` (the old Versions window) is no longer opened.
- **The look, dark and light (v0.0.369, PACK STYLE-1):** Lucas's approved mockups (`foundry/mockups/style-audit.md`, the pages `foundry/mockups/*-dark.html`). `styles/theme.css` is loaded after `styles/system.css` and is GENERATED by `tools/build-theme.mjs` from system.css (the shared colors `--s-*`, each surface's dark set made color by color, the hand rules, the carousel's look B): change the script or system.css, then run `node tools/build-theme.mjs` (test t248 fails when theme.css is stale). The classes are on `<html>` (`module/theme.mjs`, the client setting Theme: Dark by default, or Light): `.twod12-type` always, `.twod12-dark` or `.twod12-light`. system.css is not regrouped.
- **The character sheet (v0.0.289, PACK SHEET):** Lucas's approved layout (`foundry/mockups/sheet-prototype.html`): `templates/actor-sheet-pc.hbs`, its data in `module/pcsheet.mjs`, the pure rules in `module/sheetmodel.mjs` (test t212), its CSS the `v0.0.289 PACK SHEET` block at the end of `styles/system.css`. Since v0.0.291 (PACK NPC-SHEET) the NPC sheet uses the same template and model (its Builder: `npcBuilderModel`; NPC helpers tested in t213); `templates/actor-sheet.hbs` is no longer used. The rules are in the book (Core Rules and its documents).
- **Traits (v0.0.180):** on sheets, the pickers and the roll dialog's preview they are grouped chips with labels (Roll, Requires, Kind, Damage, Keywords, as in the book); on chat cards they are tight chips with a short line between groups and the group's name in the tooltip.
- **Rules (v0.0.181):** the Bestiary by Stage (levels 1-4, 5-7, 8-10) with CV ×100, the PC Health factor (Level + 17) ÷ 16 and the Modifier steps at levels 5 and 8, Guard, and the book's P1 Paladin and A1 Archer (the class items keep their structure; the new class window is pack C2).
- **Automation (v0.0.186):** cards are automated with settings on their items that you can edit (once per round, only against the marked creature, `[Mod]` in Bonus Damage, Ignore a Bane, Rally Points), not with code that tests their names. Talents carry their Category, Prerequisites (typed rows) and Theme as data. **v0.0.207 (editability sweep):** every card mechanic is on its item (Chat message, Weapon property, Starting Mastery settings; an Action's Weapon used); test t164 fails if a card's name appears in module/ code. The basic mechanics (no settings) are listed in foundry-backlog.md.
- **Weapon hands (v0.0.208, W):** a [Weapon] Action has a button per hand (2H, or M and O) instead of the "Which weapon?" window; a weapon remembers its hand (main / off; Swap on the Items tab); a held weapon comes before the Fists. The trait Gun and the property Firearm (D2).
- **Reactions (v0.0.272, RX):** a Reaction's moment is a setting on its item (Moment, Within, You too, Used on); when the moment comes, one chat message lists every Reaction it triggered, with Use / Pass for each owner, the GM's Skip all others and an auto-skip timer (world settings); the rows used resolve last in, first out; an Interrupt holds the damage until answered, a Trigger is offered after (`module/moment.mjs`). **v0.0.275 (RX-2):** the message is a stack card (faces, a "pick one" group per creature, slabs in their map colors, the GM's drag and Resolve), a map overlay shows it while open (`module/rxoverlay.mjs`, client setting "Reaction map overlay"), and once resolved it is edited in place into one line that unfolds (a snapshot, the frozen stack with the results).
- **Recommended module:** Quick Insert (switched on once per world when it is installed).

## Tests
`node tools/tests/run.mjs` runs every test (Node 18 or newer, no install needed). A test FAILS if it throws; CHANGED means its printed output differs from `tools/tests/expected/<name>.txt` (check the difference; accept intended changes with `--update`). Run some tests only with their names: `node tools/tests/run.mjs t44 t62`. Foundry never loads this folder.

## Compendiums
The starting content is written in `tools/content.mjs` and compiled with the Foundry CLI: install `@foundryvtt/foundryvtt-cli` outside this folder (`npm install @foundryvtt/foundryvtt-cli` in its parent), then run `node twod12/tools/build-packs.mjs` from there.
