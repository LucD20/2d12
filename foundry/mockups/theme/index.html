Foundry Theme Switch

Foundry V13 and V14 have two theme settings of their own: Interface (the sidebar, the chat log, the bars on the map) and Applications (windows and sheets), each Dark or Light, and a theme per sheet. The system also has its own setting (Theme: Dark or Light) for everything it draws. Pick a way and try the settings: the four surfaces show what each player would see.

What each way means

  • A, follow Foundry. One place to set the theme, the convention of dnd5e and Draw Steel, and the mix dnd5e documents as its default (a dark sidebar with light sheets) works as the user sets it. Foundry already follows the computer's dark or light setting. Popped-out chat messages are forced light by Foundry itself. The build: the theme file's scope changes from the system's class to Foundry's theme classes (the generator does it), and the system's setting is removed. Your current default, dark, becomes whatever each player's Foundry says.
  • B, the system's setting (today). Nothing to build. A player with Foundry in light still gets dark system sheets beside light Foundry windows, unless they set both.
  • C, both. A's behavior by default, with a way to force one look on the system's surfaces only. One more setting to explain.
