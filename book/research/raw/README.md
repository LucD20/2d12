# Raw research reports

The full reports behind the topic files one folder up, as the research agents wrote them (long: every rule text, excerpt and link). Not in the Project's knowledge files; the topic files are the summary. Each report says at its top how far it can be trusted.

**2026-11-14 (the Paladin's brief):** the cloud session could open only GitHub. Rules text was read in full from GitHub copies (Draw Steel, Lancer, ICON, Nimble, Fabula Ultima, the 13th Age 1e SRD, a crawl of the 4e Compendium). Everything from forums, blogs, Archives of Nethys and Paizo is a search-result summary of a page nobody opened: a lead, not a checked quote.

**The second pass (the same day, after Lucas opened the network):** the `-verified.md` files check each lead of the reports above against its page: VERIFIED (the exact sentence, the poster, the date, the link), CORRECTED, NOT ON PAGE, COULD NOT OPEN. Where a report and its verified file differ, the verified file wins. Pages are read with plain requests; a site that answers 403 (Giant in the Playground, RPG.net, Reddit) is left alone.
