# Research notes

What Claude found when Lucas asked for research outside the project (other games, design essays, forums), so a later session reads it before searching again. **These are other people's opinions and other games' rules, not 2d12's:** Lucas decides the rules. Each file is one topic; add a dated section when the topic is researched again, and a new file for a new topic.

**Each file holds:** the date and the question asked, the takeaways (short), how each applies to 2d12 (the cards or rules it touched), and the sources as links. A source that could not be read (a blocked or dead site) is listed as such.

**How far a note can be trusted (since 2026-11-14):** a note says at its top what was read. Rules text read in full is marked [read]; an opinion seen only as a search tool's summary of a page nobody opened is a [lead], to check before it is quoted to anyone. The cloud session of 2026-11-14 could open only GitHub, so that day's five notes are rules read in full plus leads; their full reports are in `raw/` (not in the knowledge files).

**For Claude:** before a web search, read the file for that topic here; search only for what it doesn't cover, then add what you found. The files go into the Project's knowledge (`tools/knowledge.py`, as `research-*.md`).
