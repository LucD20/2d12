# The layout of an ability block (a card)

## 2026-11-15: for the Action card's new structure, part 1 (the header)

**The question (Lucas):** he chose a header like Draw Steel's grid, but doubted the roll written as a sentence ("Each target makes an Appeal Save"), since the games he knows just print "X Save": "for ease of mind, do make a search about cards layout."

**How far to trust this file.** One pass, by an agent; not re-checked. [read] = a real block read in full (4e, Draw Steel, Pathfinder 2e legacy and Remaster, 5e 2014 and 2024, 13th Age's basic attack, Lancer, ICON). [checked] = an opinion read on its page (EN World, Paizo's forum, D&D Beyond, The Alexandrian). Reddit, Giant in the Playground and RPG.net refuse readers and were left alone. Gloomhaven was not done. The full report with the blocks quoted: `raw/2026-11-15-card-layout.md`.

### Takeaways

1. **Where the roll or the save is written: five ways.** [read]
   - A labeled line in the body, under the target: 4e, 13th Age ("Attack: Strength vs. Will").
   - A labeled field in the header, usually repeated as a sentence below: Pathfinder 2e's spells ("Defense Will" in the Remaster, "Saving Throw Will" before). Its actions and feats have no field, only a sentence.
   - A labeled lead-in that opens the body: D&D 2024's monsters ("Dexterity Saving Throw: DC 17, each creature in a 30-foot Cone. Failure: ... Success: ..."), Draw Steel ("Power Roll + Intuition:").
   - A sentence in the prose: 5e 2014, 5e 2024's spells, Lancer.
   - A tag: ICON's "Attack", Draw Steel's "I < AVERAGE".
   - **No published game found opens a player's ability with "Each target makes an X Save".** The nearest is the labeled lead-in, which holds the same information as a label.
   - *For 2d12:* Lucas's doubt is supported. The roll goes on a labeled line that opens the body, right above the Tiers it decides.
2. **For a dedicated line.** [checked]
   - D&D Beyond's staff on the 2024 stat block (January 2025): it "places the key information upfront. You're immediately told that a saving throw is required and how it targets creatures."
   - A Paizo forum poster, May 2018, when the playtest preview had the save only in prose: "the first question is always 'what do I roll?' so the attack / save / etc needs to be called out." The 2019 book had the line.
   - EN World, 2014: "information that you'll pretty much need to know every casting"; a sentence is faster on a first read, "of course slower" when re-checking.
   - *For 2d12:* a card is re-checked at the table far more often than it is read for the first time.
3. **For a sentence.** [checked, EN World, 2014] "you don't need to change your gaze from the text to the save or target line"; it avoids "Save: None" lines; "I don't like spellbooks to look like spreadsheets, no matter how easy it makes things."
   - *For 2d12:* the gaze argument is answered by putting the line next to the Tiers, not up in the header. No card prints an empty field.
4. **A grid with no labels is hard on a first reading.** [checked, EN World, 2025] Draw Steel's format "reminds me strongly of D&D 4e and it is similarly difficult to parse on first reading, but i am sure it will get easier with practice". The Steel Compendium's website prints the same four facts as four labeled rows (Keywords / Action / Distance / Target).
   - *For 2d12:* keep the grid's fixed places, and keep the labels on Distance, Area and Target (our draft already has them).
   - The evidence here is thin: no source compares a grid with stacked lines, and no complaint about wrapping on a phone or a virtual tabletop turned up.
5. **4e's block as a whole:** praised as clear ([checked] Justin Alexander, 2011: "4th Edition has some great formatting") and blamed for sameness ("how boringly similar all those powers end up being").
   - *For 2d12:* sameness is a matter of the look and of the cards' content, for later.
