## Commands
- Book: `cd book && python3 build_rules.py` (builds the seven documents; warnings are listed; "unresolved refs: 0" is the goal). `python3 build_rules.py --where Flanking`.
- System tests: `cd foundry/twod12 && node tools/tests/run.mjs` (120 tests; each has an expected output in tools/tests/expected; after a change that is meant, accept it with `node tools/tests/run.mjs --update t84`).
- Compendiums: the content is written in `tools/content.mjs` and compiled with the Foundry CLI: `cd foundry && npm install @foundryvtt/foundryvtt-cli` (outside the system folder), then `node twod12/tools/build-packs.mjs`. Packs: classes, features, actions, weapons, effects, conditions, npcs, pcs.
- Package for the user: zip the `twod12` folder (without node_modules) as `twod12.zip`, bump `version` in system.json, add the changelog entry to docs/reference.md (copy it to foundry/reference.md), run the tests from a fresh unzip.
- Lint: `cd foundry/twod12 && npx eslint@8 --no-eslintrc -c tools/eslint.json --ext .mjs module` (no undefined names, no unused imports or variables; it should report nothing).
- Code map: sheets are actor-sheets.mjs, item-sheet.mjs, versions.mjs, sheet-common.mjs (sheets.mjs only re-exports them); the Effect editor is fxdetails.mjs (sentences, pure), fxsync.mjs (applied effect <-> settings, pure), fxopen.mjs (where a click goes), fxapplied.mjs (the editor of an applied effect); shared helpers in util.mjs.
- Console tools in Foundry (for the user to run): `game.twod12.lightInfo()`, `visionInfo()`, `sliderInfo()`, `rulerInfo()`, `syncVision()`, `globalLight(false)`, `shadowedEffects()`, `refreshBasics()`, `addHearing()`.
